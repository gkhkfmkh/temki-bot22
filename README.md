# Telegram Giveaway Bot

Telegram-бот для розыгрышей с админ-панелью в личных сообщениях. Администратор задаёт содержание и оформление поста, бот публикует его в выбранном канале/группе, собирает участников и выбирает победителей.

## Что умеет

- Создание розыгрыша через пошаговую панель в личке с ботом.
- Изменение заголовка, приза, текста, HTML-оформления, фото, даты завершения, количества победителей и подписи кнопки.
- Публикация поста от имени Telegram-бота.
- Кнопки-ссылки на обязательные каналы и автоматическая проверка подписки при нажатии «Участвовать».
- Защита от повторной регистрации одного Telegram-аккаунта.
- Просмотр списка участников и экспорт в CSV.
- Автоматическое завершение по дедлайну и случайный выбор победителей без повторов.
- Досрочное завершение и жеребьёвка из админ-панели.
- SQLite: участники и настройки сохраняются после перезапуска.
- Доступ к панели только для ID, указанных в `ADMIN_IDS`.

## 1. Создайте бота

1. Откройте Telegram и найдите `@BotFather`.
2. Выполните `/newbot`, задайте имя и username.
3. Скопируйте токен, который выдаст BotFather.
4. Узнайте свой Telegram user ID (например, через `@userinfobot`).

## 2. Подготовьте канал или группу

1. Добавьте созданного бота в канал/группу, где будут выходить розыгрыши.
2. Для канала назначьте бота администратором с правом **публиковать сообщения**. Для обновления/удаления старого поста желательно также выдать право удаления сообщений.
3. Для проверки подписки добавьте бота администратором в каждый канал, подписку на который будете требовать.
4. Для публичного канала достаточно его username, например `@my_giveaways`.
5. Для приватного канала/группы понадобится числовой ID вида `-1001234567890`.

Чтобы узнать ID группы, добавьте бота в группу и отправьте `/id`. Бот ответит ID текущего чата.

## 3. Настройте проект на Windows

Требуется **Python 3.11 или новее**. Зависимость `tzdata` устанавливается вместе с проектом для корректной работы часовых поясов на Windows.

1. Распакуйте архив в отдельную папку.
2. В этой папке скопируйте `.env.example` и назовите копию `.env`.
3. Откройте `.env` в Блокноте и заполните:

```dotenv
BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
ADMIN_IDS=ВАШ_TELEGRAM_ID
DEFAULT_TARGET_CHAT_ID=@my_giveaways
TIMEZONE=Europe/Moscow
DB_PATH=data/giveaways.db
LOG_LEVEL=INFO
```

`DEFAULT_TARGET_CHAT_ID` можно оставить пустым и задать канал позже через меню бота. Несколько администраторов задаются через запятую: `ADMIN_IDS=123456789,987654321`.

4. Откройте терминал в папке проекта и выполните:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Для следующего запуска достаточно открыть папку проекта, активировать окружение и выполнить `python main.py`. Также можно запустить `start_windows.bat` после установки зависимостей.

## 4. Первый запуск и публикация

1. Пока программа работает, откройте ссылку своего бота в Telegram и нажмите **Start**.
2. Администратор увидит панель управления. Если панель не появилась, отправьте `/admin`.
3. Нажмите **«Чат публикации»** и отправьте `@username` или ID `-100...`.
4. Нажмите **«Создать розыгрыш»** и последовательно заполните шаги.
5. Для предпросмотра нажмите **«Предпросмотр»**.
6. Для публикации нажмите **«Опубликовать»**.

Пока розыгрыш активен, второй создать нельзя. Сначала завершите текущий розыгрыш или дождитесь автоматического подведения итогов.

## 5. Оформление текста

Текст редактируется прямо в личных сообщениях с ботом. Можно отправить текст с форматированием через стандартную панель Telegram или использовать HTML-разметку вручную:

```html
🚗 <b>В этот раз дарим Toyota Camry!</b>

🎁 А ещё — <b>2000 сертификатов Ozon</b>.

✅ Участие абсолютно <b>БЕСПЛАТНО</b>.

1️⃣ Перейдите по ссылке и подпишитесь на канал.
2️⃣ Нажмите кнопку «Участвовать».
3️⃣ Дождитесь результатов розыгрыша.

🍀 Удачи всем!
```

Полезные теги: `<b>жирный</b>`, `<i>курсив</i>`, `<u>подчёркнутый</u>`, `<s>зачёркнутый</s>`, `<code>моноширинный</code>`, `<a href="https://example.com">ссылка</a>`. Текст и эмодзи можно полностью менять без изменения кода.

Бот добавляет к вашему тексту заголовок, блок с призом и дату итогов. Если загружено фото, оно публикуется отдельным сообщением над основным постом: так длинный текст не ограничивается лимитом подписи к фото.

## 6. Условия обязательной подписки

В мастере создания отправьте по одному каналу на строке:

```text
@my_channel
@second_channel
```

Для приватного канала передайте ID и ссылку приглашения:

```text
-1001234567890 | https://t.me/+InviteCode
```

Чтобы отключить проверку подписок, отправьте `-`.

Проверка работает только тогда, когда бот может получить данные об участнике канала. Поэтому добавьте бота администратором во все каналы, подписку на которые требуется проверить. Перед запуском настоящего розыгрыша проверьте этот сценарий тестовым аккаунтом.

## 7. Команды

- `/start` — открыть бота.
- `/admin` — открыть админ-панель (только для администраторов).
- `/id` — показать ID текущего чата.
- `/cancel` — отменить текущий шаг настройки.

## 8. Запуск на сервере через Docker (необязательно)

В корне проекта уже есть `Dockerfile` и `compose.yaml`. Создайте и заполните `.env`, затем выполните:

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

## Важные ограничения

- В этой версии одновременно ведётся один активный розыгрыш. История закрытых розыгрышей и списки участников остаются в базе.
- Все даты вводятся в часовом поясе, заданном в `.env` (по умолчанию Москва).
- Победители выбираются случайно из зарегистрированных пользователей; повторные заявки одного Telegram ID не учитываются.
- Telegram не позволяет боту проверять подписку на канал, где у него нет необходимых прав. Это нужно настроить до публикации.
- Не передавайте токен бота посторонним. Если токен утёк, перевыпустите его через BotFather и замените в `.env`.
